# Moeng Tlotlo - Virtual CV Portfolio

## Overview
This repository contains the source code for my personal Virtual CV. It is a dynamic, responsive portfolio website built to showcase my academic achievements, technical skills, and career aspirations as an IT student at North-West University.

**Live Website:** [Click here to view my Virtual CV](https://razmos07.github.io/MoengTlotlo-Portfolio/) *(Update this link if your repo name is different)*

## Elements of the Virtual CV
This website is structured into the following key sections:
1. **Hero Section:** Features a professional profile picture, a brief introduction, and quick links to my social media (GitHub, LinkedIn, Email).
2. **About Me:** A personal summary highlighting my passion for technology and research.
3. **Education:** Details my Bachelor of Information Technology degree, expected graduation (2027), and relevant modules like System Analysis, Database Systems, and Web Development.
4. **Core Competencies:** Divided into Technical Skills (C#, Java, SQL, Web Tech) and Professional Skills (Research, Teamwork, Time Management).
5. **Projects/Academics:** Highlights my university coursework, including IT Research Projects and the Web Task Manager Application.
6. **Achievements & Certificates:** Showcases academic excellence, teamwork recognition, and online course certificates.
7. **Interests:** Personal interests including IT innovation, sports, and digital marketing.
8. **Career Objectives:** My professional goals in system analysis and IT project management.
9. **Contact & References:** Full contact details, social media handles (Instagram, Facebook), and university reference information.

## Technologies Used
- **HTML5:** For semantic structure and content.
- **CSS3:** For modern styling, Flexbox/Grid layouts, and responsive design.
- **JavaScript:** For smooth scrolling navigation and interactive elements.
- **Font Awesome:** For professional UI icons.
- **GitHub Pages:** For hosting and deploying the live website.

## How to Run Locally
1. Clone this repository: `git clone [your-repo-url]`
2. Open the `index.html` file in any modern web browser.
